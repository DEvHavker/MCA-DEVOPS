This repo is for MCA class practicals 
Certain word documents have been added for testing purpose

make sure to add your github username and email  to env variable using gollowing command 

git config --global user.name "YOUR_GITHUB_USERNAME"
git config --global user.email "your_email@example.com"

Steps :- 
1. clone the repo
git clone https://github.com/DEvHavker/MCA-DEVOPS.git

2. change the directory
cd MCA-DEVOPS

3. add files manually 

4 stage the files
git add .

5. commit the files
git commit -m "added word files"

6. push the files 
git push

7. Pull to keep repo up to  date
git pull
